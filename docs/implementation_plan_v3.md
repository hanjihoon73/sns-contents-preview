# [구현 계획서 v3] 인스타그램 캐러셀 동영상(MP4) 지원 및 미디어 순서 조정 기능

## 1. 개요 및 목적
현재 서비스는 인스타그램 및 유튜브 피드에 **이미지(JPG, PNG, WebP 등)**만 업로드하여 미리보기를 지원하고 있습니다.  
그러나 실제 인스타그램 캐러셀(슬라이드) 게시물은 **이미지와 동영상(MP4, MOV)을 자유롭게 혼합**하여 발행하는 경우가 매우 많습니다.

본 계획은 인스타그램 캐러셀에 **동영상(MP4)을 추가·삭제하고, 이미지와 동영상의 순서를 자유롭게 드래그하여 배치하며, 실제 앱처럼 부드럽게 미리보기(재생/정지)**할 수 있도록 시스템을 확장하는 계획입니다.

## 3. 핵심 기능 기획 (비개발자 친화적 설명)

### ① 동영상(MP4) 업로드 & 썸네일 자동 캡처
- **어떻게 동작하나요?**  
  사용자가 파일 선택 창이나 드래그 앤 드롭으로 `.mp4` 동영상 파일을 넣으면, 웹 브라우저가 동영상의 첫 장면(0.1초 시점)을 실시간으로 캡처해 **작고 가벼운 썸네일 이미지**를 자동으로 만들어냅니다.
- **왜 필요한가요?**  
  동영상 원본을 목록에 그대로 띄우면 브라우저가 느려지지만, 캡처된 썸네일을 띄우면 10개 이상 올려도 버벅임 없이 즉시 정렬할 수 있습니다.

### ② 이미지와 동영상의 자유로운 순서 정렬 (드래그 앤 드롭)
- 업로드된 목록 카드 우측 하단에 **비디오 아이콘(▶)과 영상 길이(예: 0:15)** 배지가 붙어, 어떤 항목이 사진이고 어떤 항목이 영상인지 한눈에 구분할 수 있습니다.
- 기존과 동일하게 마우스로 카드를 꾹 눌러 앞뒤로 끌어다 놓으면 이미지와 동영상의 순서가 자유자재로 바뀝니다.

### ③ 인스타그램 피드 실제 앱과 동일한 비디오 UX
- **슬라이드 도착 시 자동 재생**: 캐러셀을 넘겨 동영상 슬라이드가 화면에 나타나면 영상이 부드럽게 재생되고, 다른 사진이나 영상으로 넘어가면 자동으로 멈춥니다.
- **반복 재생 & 무음 시작**: 실제 인스타그램 피드처럼 기본 무음(muted)으로 무한 반복 재생됩니다.
- **터치/클릭 제어**: 영상을 탭하면 일시정지/재생을 직접 조작할 수 있습니다.

### ④ IndexedDB 대용량 안전 저장
- 동영상은 이미지보다 파일 크기가 크기 때문에(수 MB~수십 MB), 텍스트 문자열(Base64) 대신 브라우저 하드디스크의 **Blob(바이너리) 저장소**를 활용하여 메모리 부족 현상 없이 안정적으로 새로고침 및 복원을 지원합니다.

### ⑤ 단일 HTML 내보내기 지원
- 공유용 단일 HTML 파일(`SNS콘텐츠프리뷰_YYMMDD.html`)을 내보낼 때, 업로드된 MP4 동영상도 HTML 내부로 완벽히 번들링되어 메신저로 전달받은 상대방도 더블클릭만으로 동영상이 포함된 캐러셀을 감상할 수 있습니다.

## 4. 단계별 구현 계획 (Phase 로드맵)

규칙에 따라 각 Phase 단위로 개발을 완료하고, 제이슨의 테스트 및 확인을 거친 후 다음 단계로 순차 진행합니다.

### Phase 1: 미디어 데이터 구조 확장 및 비디오 업로더·썸네일 추출
1. **미디어 데이터 표준화**:
   - 기존: `{ id, src, name, width, height }`
   - 확장: `{ id, src, type: 'image' | 'video', name, width, height, duration, thumbnail }`
2. **동영상 썸네일 자동 추출 유틸 (`videoUtils.js`)**:
   - 브라우저 인메모리 캔버스를 통해 비디오의 메타데이터(가로, 세로, 재생시간)를 읽고, 첫 프레임을 JPEG 썸네일로 고속 생성.
3. **업로더 확장 (`ImageUploader.jsx`)**:
   - `accept` 속성에 `video/mp4,video/quicktime` 추가 및 안내 문구 업데이트.
   - 단일/다중 혼합 드롭 지원.

### Phase 2: 편집기 목록 UI 및 순서 정렬 연동
1. **미디어 카드 배지 (`SortableImageList.jsx`)**:
   - 동영상 아이템에 재생 심볼(▶) 및 재생 시간(분:초) 배지 오버레이.
   - 가로세로 비율(4:5 권장) 검사 동일 적용.
2. **드래그 앤 드롭 순서 변경 및 삭제 연동**:
   - 이미지와 동영상이 섞여 있어도 위치 이동 및 개별 삭제 정상 작동.
3. **유튜브 피드 예외 처리**:
   - 유튜브 커뮤니티는 이미지 전용이므로, 동영상이 업로드될 경우 안내 배지("유튜브는 이미지 전용") 표시.

### Phase 3: 인스타 피드 캐러셀 비디오 재생/일시정지 UX
1. **캐러셀 렌더러 확장 (`Carousel.jsx`)**:
   - 슬라이드가 `item.type === 'video'`일 때 `<video>` 요소 렌더링.
   - 슬라이드 활성화 시 `play()`, 비활성화 시 `pause()` 처리.
   - 4:5 비율에 맞춰 비디오 `object-fit: cover` 적용.
2. **인터랙션 및 UI 디테일**:
   - 재생/일시정지 토글 기능 및 비디오 로딩 중 썸네일 커버 표시.

### Phase 4: IndexedDB 저장 최적화 및 단일 HTML 내보내기
1. **IndexedDB 최적화 (`storage.js`, `useStorage.js`)**:
   - 대용량 비디오 Blob 캐싱으로 새로고침 시에도 동영상 미디어 100% 복원.
2. **단일 HTML 내보내기 확장 (`exportHtml.js`)**:
   - 비디오 미디어를 HTML 내에 DataURL로 임베딩하여 오프라인에서도 동영상 캐러셀 단독 구동 보장.
3. **최종 빌드 및 통합 사용자 검증**.

## 5. 비즈니스 권장 가이드 & 사용자 안내
- **권장 영상 길이**: 10초~60초 이내 (인스타그램 캐러셀 숏폼 권장)
- **권장 용량**: 클라이언트 브라우저 안정성과 HTML 내보내기 속도를 위해 1개당 **50MB 이하의 MP4** 권장
- **권장 비율**: 4:5 (1080 x 1350) 또는 1:1 (1080 x 1080)
